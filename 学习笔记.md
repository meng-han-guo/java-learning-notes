```java
// 把 @RestController 理解成告诉 Spring：这是一个处理 Web 请求的控制器，方法返回的结果通常要写入 HTTP 响应体。
@RestController
public class GreetingController {

  private static final String template = "Hello, %s!";
  private final AtomicLong counter = new AtomicLong();

  // 处理请求的方法，当收到路径为 /greeting 的 GET 请求时，交给下面的 greeting 方法处理。
  @GetMapping("/greeting")
  // 从请求参数中获取 name 的值，交给 Java 方法里的 name 变量。（如果请求时没有提供 name，就使用默认值World）
  public Greeting greeting(@RequestParam(defaultValue = "World") String name) {
    return new Greeting(counter.incrementAndGet(), template.formatted(name));
  }
}
```

>http://localhost:8080/greeting?name=Tom 表示找到本机 8080 端口上的程序，请求 `/greeting`，并告诉它名字是 Tom。

> `%s` 是一个**占位符**(表示要填一个字符串)

* 四种常用请求方式：GET、POST、PUT、DELETE，对应 **查、增、改、删**
